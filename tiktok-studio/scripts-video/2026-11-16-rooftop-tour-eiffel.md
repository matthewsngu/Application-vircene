# Rooftop Tour Eiffel — analyse avant publication

Brut : 10,9 s · plan fixe mi-corps (pas un selfie) · trench cuir noir à nœud, épaule dénudée · elle parle / lip-sync
La Tour Eiffel (avec le faisceau) est cachée par elle jusqu'à ~3,3 s, puis révélée quand elle se décale.

## Contrôle vs combo gagnant
| Ingrédient | Statut |
|---|---|
| Paris de nuit + monument | OK (Tour Eiffel + faisceau, vue sur les toits) |
| Look noir + blonde | OK (meilleure tenue des 3) |
| Selfie proche | NON : plan posé, visage plus petit |
| 6-8 s, sans paroles | NON : 10,9 s, elle parle |
| Révélation du monument | OK mais trop tard (3,3 s) |
| Boucle | OK (tour cachée au début et à la fin) |
| Décor luxe | OK (rooftop) |
| 1re image | Faible : 40 % de ciel noir, bouche ouverte en pleine phrase |

## Verdict
Potentiel moyen tel quel, bon après montage. C'est aussi un test utile : est-ce que le selfie est indispensable ?
