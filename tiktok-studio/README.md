# tiktok-studio

Dossier de travail du skill `/outliers-tiktok` (voir `.claude/skills/outliers-tiktok/SKILL.md`).

- `config.json` : profil de l'influenceuse et comptes/hashtags surveillés (copie de `config.example.json`, créée au premier lancement).
- `scans/` : résultats bruts des scans (JSON Apify ou CSV saisi à la main).
- `scripts-video/` : un fichier Markdown par vidéo (analyse de l'outlier, script, versions).
- `journal.csv` : vidéos publiées et leurs stats à 24 h / 72 h / 7 j.
